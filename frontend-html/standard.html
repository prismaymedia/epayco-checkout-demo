📝 Código de Ejemplo

// Configurar Standard Checkout
const checkout = ePayco.checkout.configure({
  sessionId: "68f7d482fbed825e47779c06",
  type: "standard",
  test: true
});

// En Standard, menos eventos están disponibles
// pero ofrece mayor flexibilidad

// Abrir checkout
checkout.open();

El checkout se abrirá en una nueva ventana con el flujo completo
