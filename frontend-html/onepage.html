📝 Código de Ejemplo

// Configurar OnePage Checkout
const checkout = ePayco.checkout.configure({
  sessionId: "68f7d482fbed825e47779c06",
  type: "onepage",
  test: true
});

// Event handlers disponibles
checkout.onCreated(() => {
  console.log("Checkout creado");
});

checkout.onErrors(errors => {
  console.error("Error:", errors);
});

checkout.onClosed(() => {
  console.log("Checkout cerrado");
});

// Abrir checkout
checkout.open();

Este botón cargará dinámicamente el script de ePayco y abrirá el checkout
